# Native Area Submission Research Candidate

This source is an isolated, default-off research candidate. It is not included in the main project source list, has no user-mod, loading-extension, area-extension, threading-extension or Harmony registration, and is not an installable game integration. It does not implement the existing INativeStartupSubmission interface; its Submit is a separate research signature. The existing production submission entries remain unavailable.

The candidate source is compiled only when FULLMAP_NATIVE_AREA_SUBMISSION_EXPERIMENT is defined and neither RELEASE nor FULLMAP_RELEASE is defined. The research Submit ignores its arguments and always returns Unavailable; no ordinary public call, setting or external request is connected to its private Core. The private core is present in the experimental assembly and contains real ICities.IThreading.QueueSimulationThread(Action) and ICities.IAreas.UnlockArea(x, z, false) call sites. Full-trust code in the same process can use reflection to reach private methods, so private visibility is not a security sandbox. Do not install or load this research assembly in the game.

The private core accepts at most one valid dispatch per instance, validates each coordinate in the range 0 through 4, and guards one callback entry. A queue that accepts an action without delivering it may remain Pending indefinitely. After the writer call returns or throws, the state is set to Unknown and prevents another dispatch through that instance. While the writer call is in progress, the result may remain Pending and side effects may already have occurred, so Pending does not prove that no write occurred. A queue exception can set Unknown earlier, including while the writer call is in progress. A void return is not proof of game execution, success, lack of debit or rollback. A callback that already passed its guard may still call the provider after an exception or lifecycle change. The code has no authenticated city, simulation-thread, provider, pause or unload boundary, and independent instances are not globally coordinated.
