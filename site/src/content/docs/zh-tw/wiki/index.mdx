## 模組

| 模組 | 狀態 | 目前能做什麼 |
| --- | --- | --- |
| [AI Improve](/Cities_Skylines_1_Modpack/zh-tw/wiki/ai-improve/overview/) | 已在 Workshop 發布 | 讓車輛、公共服務與市民依壅塞、閒置運能與附近需求做反應。共 25 項可開關功能。 |
| [Automated Public Transport Planning](/Cities_Skylines_1_Modpack/zh-tw/wiki/transport/overview/) | 開發原型 · 遊戲驗收待完成 | 預覽路線提案，並可在確認後嘗試建立路線；可能修改存檔。 |
| [AI Gaming](/Cities_Skylines_1_Modpack/zh-tw/wiki/ai-gaming/overview/) | 開發預覽版 · 遊戲內執行尚未驗證 | 提供配對的 Windows x64 輔助程式，讓玩家確認後取得 Ollama Local 建議。 |

<p>獨立運作及相容性是設計目標；模組組合驗收尚未完成。</p>
