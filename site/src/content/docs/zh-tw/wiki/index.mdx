## 模組

| 模組 | 狀態 | 目前能做什麼 |
| --- | --- | --- |
| [AI Improve](/Cities_Skylines_1_Modpack/zh-tw/wiki/ai-improve/overview/) | 有工作坊發布記錄 · 現時可用性未重新核實 | [公開開發版原始碼 `75ef944`](https://github.com/KingsleyHK0323/Cities_Skylines_1_Modpack/blob/75ef94407962817051cef4aa74ec6fbc1831fd02/SettingsPageUI.cs) 旨在讓車輛、公共服務與市民依壅塞、閒置運能與附近需求做反應；原始碼的靜態內容有 25 個開關。遊戲內驗收尚未完成，工作坊穩定版數量亦未獨立核實。 |
| [Automated Public Transport Planning](/Cities_Skylines_1_Modpack/zh-tw/wiki/transport/overview/) | 開發原型 · 遊戲驗收待完成 | 預覽路線提案，並可在確認後嘗試建立路線；可能修改存檔。 |
| [AI Gaming](/Cities_Skylines_1_Modpack/zh-tw/wiki/ai-gaming/overview/) | 開發已暫緩 · 較早預覽版的遊戲內執行尚未驗證 | 較早開發版配對 Windows x64 輔助程式，讓玩家確認後取得 Ollama Local 建議；目前可安裝檔案的供應情況尚未核實。 |

<p>獨立運作及相容性是設計目標；模組組合驗收尚未完成。</p>
