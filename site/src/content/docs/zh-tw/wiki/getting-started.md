> **開發版更新，2026 年 10 月 31 日：**三個模組另有實驗性 GitHub 預覽版本。最新下載、依賴及存檔風險請見[開發版下載與安裝](/Cities_Skylines_1_Modpack/zh-tw/wiki/development-downloads/)。同一模組不可同時啟用多個版本。

## 1. 訂閱依賴模組

- **[Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2040656402)**：AI Improve 必須使用。這是許多 Cities: Skylines 模組共用、用來安全修改遊戲行為的函式庫。
- **UnifiedUI**：AI Improve 選用。安裝後，AI Improve 會在 UnifiedUI 工具列加上按鈕，不必離開城市就能調整設定。

Automated Public Transport Planning 及 AI Gaming 不需要其他模組。AI Gaming 的 GitHub 開發版需要配對的輔助程式執行檔。

## 2. 選擇正式版或開發版

穩定版透過 Steam Workshop（Steam 工作坊）發布。工作坊開發版已下架；實驗性 GitHub 開發版是獨立的發布來源，需另外下載及安裝。

| | 穩定正式版 | GitHub 開發版 |
| --- | --- | --- |
| 用途 | 日常遊玩 | 提前試用變更及協助測試 |
| 更新方式 | 發布後透過 Steam 工作坊更新 | 下載已發布的 GitHub 預覽版本 |
| 測試工具 | 不包括 | 包括（請見各模組頁面） |

**每個模組只能啟用一個版本。**測試 GitHub 開發版前，請停用其他本機或工作坊版本。連結位於各模組頁面：[AI Improve](/Cities_Skylines_1_Modpack/zh-tw/ai-improve/)、[Automated Public Transport Planning](/Cities_Skylines_1_Modpack/zh-tw/automated-public-transport-planning/)、[AI Gaming](/Cities_Skylines_1_Modpack/zh-tw/ai-gaming/)。

## 3. 啟用與設定

1. 啟動遊戲，打開 **Content Manager → Mods（內容管理員 → 模組）**。
2. 啟用模組（使用 AI Improve 時也要啟用 Harmony）。
3. 從遊戲的 **Options（選項）** 選單打開模組選項進行調整。AI Improve 的每個開關，請參考[設定說明](/Cities_Skylines_1_Modpack/zh-tw/wiki/ai-improve/settings/)。

## 4. 遇到問題時

請使用 [Issue 表單](https://github.com/KingsleyHK0323/Cities_Skylines_1_Modpack/issues/new/choose) 回報，內容包括：模組名稱與版本、你使用的其他模組、發生問題的步驟，以及遊戲輸出記錄中的相關段落。記錄檔的位置請見[常見問題](/Cities_Skylines_1_Modpack/zh-tw/wiki/ai-improve/faq/)。張貼前請先刪除 Windows 使用者名稱等個人資料。
