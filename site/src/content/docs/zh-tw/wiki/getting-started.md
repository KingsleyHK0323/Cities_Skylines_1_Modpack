> **GitHub 開發版：** 目前公開可安裝檔案的供應情況尚未核實，亦可能改變；請查看 [GitHub Releases（發行清單）](https://github.com/KingsleyHK0323/Cities_Skylines_1_Modpack/releases)中的實際附件，自動產生的原始碼壓縮檔不是可直接安裝的版本。AI Gaming 開發已暫緩。依賴及存檔風險請見[開發版下載與安裝](/Cities_Skylines_1_Modpack/zh-tw/wiki/development-downloads/)。同一模組不可同時啟用多個版本。

## 1. 訂閱依賴模組

- **[Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2040656402)**：AI Improve 必須使用。這是許多 Cities: Skylines 模組共用、用來安全修改遊戲行為的函式庫。
- **UnifiedUI**：AI Improve 選用。[公開開發版原始碼 `75ef944`](https://github.com/KingsleyHK0323/Cities_Skylines_1_Modpack/blob/75ef94407962817051cef4aa74ec6fbc1831fd02/IngameUI.cs) 的面板提供空載城際列車及公車掃描，以及重設設定；個別功能設定位於模組的 Options（選項）頁。這是靜態原始碼核對，工作坊穩定版介面未經獨立遊戲驗證。

Automated Public Transport Planning 及 AI Gaming 不需要其他模組。如有官方可安裝的 AI Gaming 開發版，還需要配對的 Windows x64 輔助程式執行檔。

## 2. 選擇正式版或開發版

各模組的 Steam Workshop（Steam 工作坊）發布記錄及現時可用性各有不同，這裏未重新核實；請查看各模組頁面的連結。如有官方可安裝的實驗性 GitHub 開發版，需另外下載及安裝。

| | 穩定正式版 | GitHub 開發版 |
| --- | --- | --- |
| 用途 | 日常遊玩 | 提前試用變更及協助測試 |
| 更新方式 | 發布後透過 Steam 工作坊更新 | 查看 GitHub 發行清單及版本附帶的可安裝檔案 |
| 測試工具 | 不包括 | 視乎版本而定；請查看該版本的說明 |

**每個模組只能啟用一個版本。** 測試 GitHub 開發版前，請停用其他本機或工作坊版本。連結位於各模組頁面：[AI Improve](/Cities_Skylines_1_Modpack/zh-tw/ai-improve/)、[Automated Public Transport Planning](/Cities_Skylines_1_Modpack/zh-tw/automated-public-transport-planning/)、[AI Gaming](/Cities_Skylines_1_Modpack/zh-tw/ai-gaming/)。

## 3. 啟用與設定

1. 啟動遊戲，打開 **Content Manager → Mods（內容管理員 → 模組）**。
2. 啟用模組（使用 AI Improve 時也要啟用 Harmony）。
3. 在內容管理員開啟模組的 **Options（選項）** 頁面進行調整。AI Improve 的[設定指南](/Cities_Skylines_1_Modpack/zh-tw/wiki/ai-improve/settings/)使用[公開開發版原始碼 `75ef944`](https://github.com/KingsleyHK0323/Cities_Skylines_1_Modpack/blob/75ef94407962817051cef4aa74ec6fbc1831fd02/SettingsPageUI.cs) 的資料；實際安裝的版本可能不同，遊戲內行為尚未驗證。

## 4. 遇到問題時

請使用 [Issue 表單](https://github.com/KingsleyHK0323/Cities_Skylines_1_Modpack/issues/new/choose) 回報，內容包括：模組名稱與版本、你使用的其他模組、發生問題的步驟，以及遊戲輸出記錄中的相關段落。記錄檔的位置請見[常見問題](/Cities_Skylines_1_Modpack/zh-tw/wiki/ai-improve/faq/)。張貼前請先刪除 Windows 使用者名稱等個人資料。
