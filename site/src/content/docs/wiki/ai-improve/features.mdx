The public [Development source at `75ef944`](https://github.com/KingsleyHK0323/Cities_Skylines_1_Modpack/blob/75ef94407962817051cef4aa74ec6fbc1831fd02/SettingsPageUI.cs) defines 25 feature switches and one tuning-only card. The tuning-only card is in the Advanced section, which appears when *Show advanced tuning values* is enabled. Not every card has a switch.

The cards below use the data bundled with this site; its source commit and extraction date are shown above the cards. **On / Off** labels reflect defaults in that data. This static source review does not establish in-game behavior or that the stable Workshop version matches it.

Open the mod's full settings from AI Improve's **Options** page in Content Manager. In this Development source, the optional UnifiedUI panel provides empty intercity train and bus scans and a settings reset, not the full settings page.
